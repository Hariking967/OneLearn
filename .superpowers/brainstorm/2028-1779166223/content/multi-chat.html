Multiple Chats Per Topic — how should they work?

Each topic can have multiple chat sessions. What's the memory model?

A

Isolated sessions — no shared memory

Each chat starts fresh. Chat 1 history doesn't bleed into Chat 2. Good for "practice session" vs "study session" use cases. RAG from project resources still applies to all.

B

Shared topic memory — separate threads

All chats under a topic share the same compressed topic memory (what you've learned). Each chat has its own message history but the AI "remembers" progress across all of them.

C

Named sessions — fully independent

User names each chat (e.g. "Study session", "Exam prep", "Homework help"). Each is totally separate — own history, own memory. Like separate notebooks for the same topic.
